# 📝 To-Do List App

A simple and responsive To-Do List web application built using **HTML, CSS, and JavaScript**. This application helps users organize their daily tasks by allowing them to add, complete, and delete tasks. All tasks are stored in the browser's localStorage, ensuring data persists even after refreshing or reopening the page.

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Persistent data storage using localStorage
* Clean and responsive user interface
* Fast and lightweight

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
